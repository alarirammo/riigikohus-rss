# Riigikohtu lahendite RSS

Genereerib RIK-i lahendite lehest RSS-voo Feedly jaoks. GitHub Actions uuendab faili `rss.xml` kord tunnis.

Peale GitHubi importimist kaivita Actions -> Update Riigikohtu RSS -> Run workflow. Kui `rss.xml` on tekkinud, luba GitHub Pages (main branch, root). Feedly URL on `https://KASUTAJANIMI.github.io/riigikohus-rss/rss.xml`.
